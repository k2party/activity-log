行動記録メモ 管理者マニュアル

管理者（ユーザID admin）向けのマニュアルです。ユーザーの登録・管理と、利用者の帳票の出力について説明します。 一般ユーザーの操作（行動の記録・感想・AI 要約など）は「利用マニュアル」を参照してください。

このマニュアルには初期パスワードなど、管理に関わる情報が含まれます。一般ユーザーには配布しないでください。

1. 管理者の役割

管理者は、ユーザID admin の1アカウントだけです（削除できません）。管理者ができること・できないことは次のとおりです。

できることできないこと
  • ユーザーの追加・氏名変更・パスワードの再設定・削除
  • 各ユーザーの Gemini API キーの設定状態の確認
  • 任意のユーザーの帳票（PDF）・CSV の出力
  • 行動記録・感想の入力・編集（管理者の画面には入力欄が出ません）
  • 他のユーザーの記録の編集・削除
  • 他のユーザーの Gemini API キーの閲覧・登録・変更（本人のみ）
  • ユーザIDの変更

2. 初めてログインしたとき

データベースを新しく作成したときに、管理者アカウントが自動で作られます。

ユーザID初期パスワード
adminactAdmin
  1. ログイン画面で上記のユーザID・パスワードを入力してログインします。
  2. 画面上部に「管理者の初期パスワードのままです」と表示されるので、「変更する」（または「パスワード変更」）を押します。
  3. 現在のパスワード（actAdmin）と、新しいパスワード（8〜128文字）を2回入力して 「変更する」 を押します。

初期パスワードは公開されている値です。必ず最初に変更してください。

3. ユーザーを追加する

  1. 画面上部の 「ユーザ管理」 を押します。
  2. 「ユーザー追加」に次の項目を入力し、「追加」 を押します。
    項目入力ルール
    ユーザID半角英数字と _ . @ - で32文字以内。大文字・小文字の違いだけの重複はできません。登録後は変更できません
    氏名50文字以内。帳票（PDF）のヘッダに印刷されます
    パスワード8〜128文字
  3. 追加したユーザーに、ログインするアドレス・ユーザID・パスワードを伝えます。あわせて「利用マニュアル」（ログイン画面からダウンロードできます）を案内してください。
  • パスワードは安全な方法で伝え、ユーザー本人に「パスワード変更」で変えてもらうことをおすすめします。
▲ 目次へ戻る

4. ユーザーの氏名・パスワードを変更する

  1. 「ユーザ管理」の「ユーザー一覧」で、対象ユーザーの行を探します。
  2. 氏名を変える場合は 氏名 の欄を書き換えます。
  3. パスワードを再設定する場合は 新しいパスワード の欄に入力します（変えない場合は空欄のまま）。
  4. その行の 「保存」 を押します。
  • パスワードを再設定すると、そのユーザーはすべての端末でログアウトされ、新しいパスワードでの再ログインが必要になります。
  • ユーザーがパスワードを忘れたときは、この手順で再設定して本人に伝えてください。
  • 管理者自身のパスワードもこの画面で変更できます（行動記録画面の「パスワード変更」でも変更できます）。
▲ 目次へ戻る

5. ユーザーを削除する

  1. 「ユーザ管理」の「ユーザー一覧」で、対象ユーザーの行の 「削除」 を押します。
  2. 確認のメッセージで OK を押します。

削除すると、そのユーザーの行動記録・1日の感想・Gemini API キーもすべて削除され、元に戻せません。 必要な場合は、削除する前に帳票（PDF）・CSV を出力して保管してください（7章）。

  • 管理者（admin）は削除できません。

6. Gemini API キーの設定状態を確認する

感想の AI 要約は、各ユーザーが自分の Gemini API キーを「Gemini設定」で登録したときだけ使えます。 「ユーザ管理」の一覧の 「Gemini API キー」 の列で、各ユーザーの設定状態を確認できます。

表示意味対応
...abcd設定済み（キーの末尾4文字）—
未設定キーが登録されていないAI 要約を使う場合は、本人に登録してもらいます
使用不可キーの登録はあるが、サーバーに暗号化用の秘密鍵（GEMINI_KEY_SECRET）が設定されていないサーバー管理者に秘密鍵の設定を依頼します
要再登録サーバーの秘密鍵が変わったなどで、登録済みのキーを復号できない本人に「Gemini設定」でキーを登録し直してもらいます
  • キーの中身は管理者にも表示されません。キーの登録・変更・削除は本人だけができます。
  • キーは暗号化して保存されているため、データベースのファイルだけが漏れてもキーは読めません。

7. 利用者の帳票（PDF）・CSV を出力する

管理者でログインすると、行動記録画面には入力欄・一覧の代わりに 「出力するユーザー」 の選択欄が表示されます。

  1. 「出力するユーザー」 でユーザーを選びます（管理者自身は選択肢に出ません）。
  2. 「1日」「期間」、日付、または「今日」「今週」「先月」などのボタンで、出力する期間を指定します。 画面に「（氏名）の（期間）の記録：n件」と件数が表示されます。
  3. 「PDF出力」 または 「CSV出力」 を押します。
出力内容
PDF出力指定期間を含む週（月曜〜日曜）ごとに、A4 横1ページの帳票を別のタブで表示します。列は「日付 / 時刻 / 行動 / メモ / 1日の感想 / 服薬時刻」で、ヘッダに期間・氏名・出力日時が入ります
CSV出力指定期間の記録を「日付 / 種類 / 開始日時 / 終了日時 / メモ」の CSV で保存します（感想は含みません）
  • ファイル名には、選んだユーザーのユーザIDと出力日時が入ります（例：行動記録_user01_2026-11-09_2026-11-15_20261115-093824.pdf）。
  • 期間は最大400日まで指定できます。
  • 夜に寝て朝に起きた睡眠は「起きた日」の記録として出力されます（一覧・PDF・CSV で共通）。

8. 困ったときは

困りごと対処
ユーザーがパスワードを忘れた「ユーザ管理」で新しいパスワードを設定して本人に伝えます（4章）
ユーザーがログインできない（失敗が続いた）同じ接続元・ユーザIDで15分間に5回失敗すると、一時的にログインできなくなります。15分ほど待ってもらいます（サーバーを再起動しても解除されます）
管理者のパスワードを忘れた画面からは再設定できません。サーバー管理者に相談してください
「そのユーザIDは既に使われています」と表示される大文字・小文字の違いだけのユーザIDは登録できません。別のユーザIDにしてください
「出力するユーザー」が選べない一般ユーザーが1人も登録されていません。先にユーザーを追加してください
Gemini API キーが「使用不可」「要再登録」になっている6章を参照してください
AI 要約がエラーになると相談された本人の API キーが無効・利用上限・Gemini の混雑が考えられます。本人に「Gemini設定」でキーを確認してもらうか、時間をおいて試してもらいます。詳しい原因はサーバーのログに出ます（サーバー管理者に確認を依頼します）
PDF の文字が表示されない日本語フォントに対応した PDF ビューア（Chrome、Edge、Acrobat Reader など）で開いてください

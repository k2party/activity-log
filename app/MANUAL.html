行動記録メモ 利用マニュアル

行動記録メモは、睡眠・食事・服薬・外出などの毎日の行動と「1日の感想」を記録し、1週間ごとの帳票（PDF）や CSV に出力できる Web アプリです。パソコンでもスマートフォンでも、ブラウザから利用できます。

1. ログイン・ログアウト

ログイン

  1. 管理者から伝えられたアドレスをブラウザで開きます。
  2. ユーザID と パスワード を入力し、ログインします。
  • ユーザID・パスワードは管理者が登録します。分からない場合は管理者に問い合わせてください。
  • ログインの失敗が続くと、しばらくの間（最大15分）ログインできなくなります。時間をおいてからもう一度お試しください。
  • 最後に使ってから 14日間 はログインしたままになります。14日以上使わないと、自動でログアウトされます。

ログアウト

画面右上の 「ログアウト」 を押します。共用のパソコンを使ったときは、必ずログアウトしてください。

3. 行動を記録する

手順

  1. 種類のボタンを押します。
    ボタン記録する内容
    🌙 睡眠就寝時刻・起床時刻（4章を参照）
    🍚 食事開始時刻・終了時刻・メモ（朝食・昼食など）
    💊 服薬服薬した時刻・メモ（朝食後・就寝前など）。終了時刻はありません
    🚶 外出出発時刻・帰宅時刻・行先
    📝 その他開始時刻・終了時刻・内容（家事・入浴など）
  2. 日付 を確認します（最初は今日の日付が入っています）。
  3. 開始時刻 を入力します。「今」ボタンを押すと現在の時刻が入ります。
  4. 終わっていれば 終了時刻 を入力します。まだ終わっていなければ空欄のままで構いません（あとから入力できます）。
  5. 必要なら メモ（行先・内容）を入力します（20文字まで）。
    • 食事・服薬は「朝食」「朝食後」などのボタンを押すと、そのまま入力されます。
    • 以前に入力したメモは、入力欄に候補として表示されます。
  6. 「〇〇を記録」 ボタンを押します。

時刻の入力方法

時刻はいろいろな書き方で入力できます。入力欄から離れると「09:30」の形にそろえられます。

入力例意味
9:30、0930、9309時30分
99時00分
９：３０、9時30分全角や「時」「分」も使えます
25:00翌日の1時00分（24時以降は翌日として扱います。47:59 まで）
  • 終了時刻が開始時刻より前の時刻なら、翌日 の時刻として扱います（例：開始 23:30・終了 1:00 → 翌日 1:00）。
  • 入力欄の下に「→ 翌01:00（1時間30分）」のように、どう扱われるかが表示されるので確認してください。

4. 睡眠と起床を記録する

寝るとき

  1. 🌙 睡眠 を押します。
  2. 就寝時刻（最初は現在時刻）を確認し、「就寝を記録」 を押します。

記録すると、入力欄に「😴 睡眠中：（就寝日時）〜（経過時間）」と表示されます。

起きたとき

  1. 🌙 睡眠 を押します（「起床を記録」に変わります）。
  2. 起床時刻（最初は現在時刻）を確認し、「起床を記録」 を押します。

一覧の睡眠の行にある 「起床」 ボタンからも、起床時刻を入力できます。

睡眠を記録する日

夜に寝て朝に起きた睡眠は、起きた日（翌日）の睡眠 として記録されます。

例記録される日
11/2 の 23:30 に寝て、11/3 の 7:00 に起きた11/3
11/3 の 1:00 に寝た11/3
11/3 の 13:00 から昼寝した11/3
11/3 の 19:00 から 21:00 まで仮眠した11/3（24時前に起きた場合は寝た日）
  • 18:00 以降に寝るときは、日付が自動で翌日になります。
  • あとから就寝を入力するときは、日付に「起きた日」 を入れてください（例：日付 11/3・就寝 23:30 → 11/2 の 23:30 に寝たことになります）。
  • 一覧・帳票・CSV はすべてこの日付で表示されます。

5. 記録を見る・直す・消す

表示する日・期間を選ぶ

操作内容
「1日」1日分を表示します（記録が無い日も表示され、感想を書けます）
「期間」開始日〜終了日を表示します（記録か感想がある日だけ表示されます。最大400日）
◀ / ▶前・次の日（期間）に移動します
今日・昨日・今週・過去7日・今月・先月よく使う日・期間をすぐに表示します（今週は月曜〜日曜）

一覧の見かた

  • 日ごとに、開始・終了・時間・行動（種類とメモ）が並び、右上に合計時間が表示されます。
  • 時刻はその日を基準に「前日 23:30」「翌07:00」のように表示されます。
  • 別の日に記録された行動がその日にかかっている場合（夜から続く外出など）は、薄い色で「（m/d に計上）」と表示されます。この行は合計に含まれません。
  • 睡眠中の行は、終了欄に「睡眠中」、時間欄に経過時間が表示されます。

終了時刻を入れる

終了時刻が未入力の行には 「終了」（睡眠は 「起床」）ボタンがあります。押すと終了時刻を入力できます。

直す

  1. 行の 「編集」 を押します。
  2. 種類・日付・開始時刻・終了時刻・メモを直します。
  3. 「保存」 を押します（やめるときは「取消」）。

消す

行の 「削除」 を押し、確認のメッセージで OK を押します。削除した記録は元に戻せません。

6. 1日の感想を書く

一覧の各日の下に「1日の感想」欄があります。1日に1件、1000文字まで書けます。

  1. 「1日」表示で感想が未入力の日は、最初から入力欄が表示されます。それ以外の日は 「入力」（書いてある日は 「編集」）を押します。
  2. 感想を入力し、「保存」 を押します。
  • 入力欄を空にして保存すると、その日の感想は削除されます。
  • 書いた感想は帳票（PDF）の「1日の感想」の欄に印刷されます。

7. 感想を AI で要約する（Gemini設定）

長く書いた感想を、Google の AI（Gemini）で短くまとめることができます。この機能を使うには、自分の Gemini API キー を登録する必要があります。キーを登録していないと「AI要約」ボタンは表示されません。

API キーを登録する

  1. Google AI Studio で API キーを取得します（Google アカウントが必要です）。
  2. 画面上部の 「Gemini設定」 を押します。
  3. API キーを貼り付けて 「保存」 を押します。
  • 登録したキーはあなたの要約にだけ使われ、ほかの人には使われません。
  • キーは暗号化して保存されます。画面には末尾4文字だけが表示されます（管理者もキーの中身は見られません）。
  • キーを消すときは、「Gemini設定」で 「キーを削除」 を押します。
  • 「サーバーに暗号化用の秘密鍵が設定されていない」と表示されて登録できない場合は、管理者に連絡してください。

要約する

  1. 感想を 50文字以上 入力します。
  2. 「AI要約」 を押します。しばらくすると、入力欄の文章が要約に置き換わります。
  3. 内容を確認し、よければ 「保存」 を押します（要約しただけでは保存されません）。
  • 元の文章に戻したいときは 「元に戻す」 を押します。
  • 要約の回数は、10分間に20回までです。
  • 要約する感想の文章は Google に送信されます。 送りたくない内容は要約しないでください。

8. 帳票（PDF）・CSV を出力する

  1. 「1日」または「期間」で、出力したい日・期間を表示します。
  2. ボタンを押します。
ボタン内容
PDF出力表示中の期間を含む週（月曜〜日曜）ごとに、A4 横1ページの帳票を別のタブで表示します。印刷や保存はブラウザ（PDF ビューア）の機能で行います
CSV出力表示中の期間の記録を CSV ファイルで保存します（Excel などで開けます）

帳票（PDF）の内容

  • 上部に「行動記録（期間）　氏名」と出力日時が入ります。
  • 列は「日付 / 時刻（FROM〜TO）/ 行動 / メモ / 1日の感想 / 服薬時刻」です。
  • 睡眠のメモ欄には睡眠時間（例：7時間30分）が入ります。
  • 服薬は「服薬時刻」の欄にまとめて表示されます。

CSV の内容

  • 列は「日付 / 種類 / 開始日時 / 終了日時 / メモ」です（感想は含みません）。
  • 睡眠のメモ欄には睡眠時間が入ります。

ファイル名

出力するたびに日時の付いた別の名前になります（例：行動記録_2026-11-09_2026-11-15_20261115-093824.pdf）。

9. パスワードを変更する

  1. 画面上部の 「パスワード変更」 を押します。
  2. 現在のパスワードと、新しいパスワード（8〜128文字）を2回入力します。
  3. 「変更する」 を押します。
  • パスワードを変更すると、ほかの端末（スマートフォンなど）でのログインは解除されます。もう一度ログインしてください。
  • パスワードを忘れた場合は、管理者に再設定を依頼してください。

10. 困ったときは

困りごと対処
ログインできないユーザID・パスワードを確認してください。失敗が続いた場合は15分ほど待ってからお試しください。忘れた場合は管理者に連絡してください
急にログイン画面に戻った14日間使わなかったか、パスワードが変更されました。もう一度ログインしてください
時刻を入力するとエラーになる00:00〜47:59 の範囲で入力してください。終了時刻は開始時刻より後にしてください
睡眠が思った日に表示されない夜に寝た睡眠は起きた日に記録されます（4章）。日付を直すときは「編集」で日付に起きた日を入れてください
24時間を超える記録を入れたいいったん記録してから「編集」で、終了欄に日付と時刻を 2026-11-20 08:00 の形で入力してください
「AI要約」ボタンが無いGemini の API キーが登録されていません（7章）
AI 要約でエラーになるAPI キーが正しいか「Gemini設定」で確認してください。混み合っている場合は、しばらくしてからお試しください
PDF の文字が表示されない日本語フォントに対応した PDF ビューア（Chrome、Edge、Acrobat Reader など）で開いてください
古い PDF / CSV が開く出力のたびにファイル名が変わります。最新の日時のファイルを開いてください
